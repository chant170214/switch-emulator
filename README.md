\# Nintendo Switch Emulator (Route C)



This is the starting point for a Nintendo Switch emulator written in C++

for Windows, using CMake and GitHub.



\## Current features

\- Project structure

\- Minimal ARM64 CPU class

\- Ready for expansion (JIT, GPU, memory system)



\## Build

mkdir build

cd build

cmake ..

cmake --build .





\## Goal (Route C)

\- Full-featured emulator

\- Capable of running commercial 3D games
